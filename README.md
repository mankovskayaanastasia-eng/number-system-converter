# Number System Converter

Учебный проект на C++ для перевода чисел между десятичной и восьмеричной системами счисления.

## Возможности программы

- Перевод из десятичной системы счисления в восьмеричную.
- Перевод из восьмеричной системы счисления в десятичную.
- Проверка правильности ввода восьмеричных чисел.
- Обработка некорректного ввода.

## Структура проекта

- `Dll1` — библиотека с функциями перевода чисел.
- `Test` — консольная программа для работы с библиотекой.
- `converter.cpp` — функции перевода чисел.
- `converter.h` — объявления функций.
- `Test.cpp` — основная программа с меню.

## Используемые технологии

- C++
- Visual Studio
- DLL (динамическая библиотека)
